- 建立日期：2026-10-14
- 適用專案：Tarot-backend
- 前置：v8 一致性、v9 正逆位極性

## 這份是怎麼來的

v8、v9 都是針對單一組牌的外部批判。這次改成**主動普查**，分兩輪：

| 輪次 | 規模 | 作法 | 樣本 |
|---|---|---|---|
| 第一輪 | 四個牌陣 × 五領域 × 各 3 題 = **60 組** | 以塔羅師角度逐項審讀全文，找出缺陷類型 | `doc/普查樣本-60組.txt` |
| 第二輪 | 四個牌陣 × 五領域 × 各 **100** 題 = **2000 組** | 把第一輪找到的 10 類寫成可檢測條件，量出真實出現率 | `doc/普查樣本-2000組.txt` |

兩輪都用固定亂數種子，可重現。自選牌陣（無位置）不在範圍內。
問題庫在 `scripts/auditQuestions.js`：每個領域 25 個主題 × 4 種問法，四種問法分別觸發不同判定分支
（問結果／問該不該／問怎麼做／**提到具體的人**，最後一種會讓宮廷牌走「人物」而非「性格」）。

**第二輪推翻了第一輪的幾個印象。** 下表是 2000 組的實測：

|---|---|---|---|

### 依牌陣拆開才看得出真相（每格 500 組）

```
                Q1   Q2   Q3  Q4a  Q4b   Q5   Q6   Q7   Q8   Q9  Q10
時間之流          4  220  136    0  110   51   10   14  264    0    0
直指核心         10  284  229    0    0  102   24   28  289  172  125
指引之星        111  409  248    0    0   95   40  164  118    0  130
塞爾特十字       203  469  317  109    0  144   50  308   67   80  112
```

這張表比總出現率有用得多，它指出三件事：

1. **Q4 不是隨機誤判，是牌陣規模的系統性偏差。** Q4a 只出現在塞爾特十字（109/500 = **21.8%**），Q4b 只出現在時間之流（110/500 = **22%**）。總出現率 5.5% 掩蓋了這件事。
2. **Q1、Q7 隨牌數遞增。** Q1 是 4 → 10 → 111 → 203，Q7 是 14 → 28 → 164 → 308。牌越多，各指標越容易分歧、重複數字越容易出現。塞爾特十字的 Q7 高達 **61.6%**。
3. **Q9、Q10 只發生在特定牌陣。** Q9 只在直指核心（172/500 = 34.4%）與塞爾特十字；Q10 在時間之流必為 0（三張牌距離不可能 ≥3）。

## 一、發現的問題

### 甲、同一份報告裡「最重要的牌」有三個答案

#### Q1 三個指標各指一張牌，而且互不相同　**328 / 2000（16.4%）**

塞爾特十字 203/500（40.6%）、指引之星 111/500，三張牌陣幾乎不會發生。**牌越多越嚴重。**

同一組牌會同時出現：

| 說法 | 來源 | 算的是 |
|---|---|---|
| 「焦點牌是**自我的吊人逆位**」 | `theme.focusIndex` | 牌本身的份量評分 |
| 「其中**現況的錢幣三正位**最能推一把」 | `quant.contributions[0]` | 對整體走向的帶動幅度 |
| 「其中**阻礙的寶劍國王**份量最重」 | `courtSummary` | 宮廷牌之間的階級比較 |

三句話分散在三個區塊，讀者的合理反應是「所以我到底該看哪一張」。

v8 把詞彙分流了（份量／說話最大聲），但**沒有解決「有三個第一名」這件事本身**。

#### Q2 宮廷牌同一句話裡自相矛盾　**1382 / 2000（69.1%）**　← 最嚴重

```
國王是宮廷裡份量最重的階級，又落在權重較高的位置，在整組裡只是輔助的角色。
侍者是宮廷裡最輕的階級，份量有限，又落在權重較高的位置，在整組裡也有一定的份量。
```

前半講階級與位置權重，後半講帶動幅度，三個量塞進一句話，彼此打架。v8 的分流讓用詞不再重複，卻讓矛盾更明顯了。

### 乙、牌對的標籤與文字對不起來

#### Q3 標籤說「增強」，文字卻是兩邊都不行　**930 / 2000（46.5%）**

```
[增強] 女祭司→聖杯四　既沒判斷也沒興致，案子很乾。
[增強] 寶劍王牌→權杖王牌　既一團亂也提不起勁，先等動力回來再說。
[削弱] 吊人→力量　不願等，好在你撐得住。
[削弱] 錢幣侍者→寶劍五　不想從頭來，好在好勝的心緩下來。
```

`relation`（增強／削弱／中性）算的是**元素關係**（火＋火增強、火＋水削弱），文字來自**辭典的牌義**。兩者本來就在講不同的事，但「增強／削弱」這組詞讀起來像價值判斷，擺在具體句子旁邊就變成打臉。

v8 的 B5 曾提議把這個徽章降級，當時沒做。現在有數據了：**五組牌裡就有一組對不上。**

### 丙、規模判定與牌陣脫鉤

#### Q4 規模判定與牌陣規模反向　**塞爾特十字 21.8%、時間之流 22%**

```
塞爾特十字｜財務｜要怎麼改善一直存不到錢的狀況
　→ 這件事的規模是生活小事。
```

會攤開十張牌問「為什麼一直存不到錢」的人，問的不是小事。

`intensity` 只算**牌卡權重的平均值**，小牌多就被拉低。十張牌裡小牌本來就多，所以大牌陣反而容易被判輕。反過來，三張牌的時間之流出現 **4 次「人生級的轉折」**。

2000 組的實測（每個牌陣 500 組）：

| 牌陣 | 判成「人生級的轉折」 | 判成「生活小事」 |
|---|---|---|
| 時間之流（3 張） | **110（22%）** | — |
| 直指核心（4 張） | 0 | — |
| 指引之星（7 張） | 0 | — |
| 塞爾特十字（10 張） | 0 | **109（21.8%）** |

兩端完全反過來：**三張牌最容易被判成人生大事，十張牌最容易被判成小事。**

**牌陣的選擇本身就表達了問題的份量**，這個訊息現在完全沒有被用到。

#### Q5 「議題偏向日常，由個人可控」忽略了重量級小牌　**392 / 2000（19.6%）**

同一組塞爾特十字裡，環境是**寶劍十正位**、自我是**吊人逆位**，卻判成「日常、個人可控」。

`dominance` 只數大牌張數。但寶劍十（polarity −0.9）、寶劍三（−0.9）這類牌在牌義上的份量不亞於一般大牌。判「可控與否」只看大小牌，不看牌義強度，塔羅上說不過去。

### 丁、階段分析

#### Q6 「後面要收尾」但終點是「開始」　**124 / 2000（6.2%）**

```
走到哪個階段：… → 環境 寶劍十（10．完成或過載） → 希望與恐懼 聖杯四（4．穩定）
　　　　　　　→ 結果 權杖王牌（1．開始）。中段衝到結束或過載，最後收在起步期。
GUIDANCE：中段衝得最高，後面要收尾。
```

`SHAPE_SUMMARY.peak` 寫死成「後面要收尾」，但數字**降到 1 代表重新開始**，不是收尾。下降在塔羅裡有兩種讀法（退回整理／結束後重啟），落點是 1 時是後者。

#### Q7 數字強調與階段序列各說各話　**514 / 2000（25.7%）**，塞爾特十字 61.6%

同一組牌：

```
[元素與數字] 數字 10 出現 3 張，「完成或過載」的主題被強調。
[走到哪個階段] …過去 錢幣十（10）→ 近未來 聖杯十（10）→ 環境 寶劍十（10）…
```

兩個區塊在講同一件事（三張 10），卻完全沒有互相引用。v8 把元素與數字獨立成段之後，這個斷裂更明顯。

### 戊、其他

#### Q8 結語把「缺少的牌組」講兩次　**738 / 2000（36.9%）**

```
…做事和衝勁、溝通和判斷、錢和實際的東西這幾塊這次沒出現，是容易被忽略的地方。
…接下來值得自己回答：…做事和衝勁這塊這次沒出現，是真的不重要，還是你暫時不想碰？
```

陳述句與提問句用同一個事實，中間只隔一句。一半的報告都有。

#### Q9 「各個位置看出什麼」整區消失　**252 / 2000（12.6%）**

| 牌陣 | 整區消失（每 500 組） |
|---|---|
| 時間之流 | 0 |
| 直指核心 | **172（34.4%）** |
| 指引之星 | 0 |
| 塞爾特十字 | **80（16%）** |

規則 8 的塞爾特十字判定（資源未發揮、環境不明朗…）**只在該位置逆位時才成立**，全正位就整區不見。直指核心同理。

#### Q10 跨位置的「互相幫上忙」沒有考慮時間距離　**367 / 2000（18.4%）**

```
[矛盾] 過去的錢幣十和近未來的聖杯十本來能互相幫上忙，但錢幣十是逆位…
```

「過去」與「近未來」隔了整個現在。說它們「本來能互相幫上忙」，沒有交代這是跨時間的呼應，讀起來像兩張相鄰的牌。

## 二、問題分類與建議改法

| # | 問題 | 出現率 | 建議 |
|---|---|---|---|
| **Q2** | 宮廷牌句內矛盾 | **69.1%** | 一句只講一件事。階級與位置歸一句，帶動幅度另起一句，中間用「不過」銜接 |
| **Q3** | 牌對標籤對不上文字 | **46.5%** | 把「增強／削弱」改成明確的元素用語（同元素／元素相剋／元素無關），不要用帶價值判斷的詞 |
| **Q8** | 結語重複缺少的牌組 | **36.9%** | 提問規則加一道「已在前文提過就換一題」的檢查 |
| Q7 | 數字強調與階段斷裂 | 25.7% | 階段序列偵測到重複數字時，直接在同一段點出「這個數字出現 N 次」 |
| Q5 | 重量級小牌不算份量 | 19.6% | `dominance` 除了大牌張數，再看高強度牌（\|polarity\| ≥ 0.8）的佔比 |
| Q10 | 跨位置關係沒講距離 | 18.4% | 關係對的文字帶上位置距離（相鄰／跨越／首尾呼應） |
| Q1 | 三個「最重要的牌」 | 16.4% | 在 `verdict` 裡選出**唯一的主牌**，其餘兩個指標降為補充，並明講各自在量什麼 |
| Q9 | 位置區塊整區消失 | 12.6% | 位置規則補上「正位時」的判定，不要只在逆位時才說話 |
| Q6 | 「收尾」但終點是 1 | 6.2% | `SHAPE_SUMMARY` 依終點數字分岔：落在 1～3 說「回到起點重來」，落在 8～10 才說「收尾」 |
| Q4 | 規模與牌陣反向 | 各牌陣 22% | `intensity` 納入牌陣規模：十張牌陣的下限提高，三張牌陣的上限壓低 |

## 三、分期

依實測出現率重排，不再依「改起來方便」排。

| 期 | 內容 | 可解掉 | 風險 |
|---|---|---|---|
| **A** | Q2 宮廷牌拆句、Q8 結語去重 | **2120 處（106%）**※ | 低。純文字 |
| **B** | Q3 牌對標籤改用元素用語 | 930 處（46.5%） | 低。後端換詞＋前端樣式 |
| **C** | Q7 數字與階段合併、Q6 階段收尾分岔 | 638 處（31.9%） | 低。同一個函式內 |
| **D** | Q4 規模納入牌陣、Q5 高強度小牌 | 610 處（30.5%） | 中。改規則門檻，會動既有測試 |
| **E** | Q1 選出唯一主牌、Q10 位置距離 | 695 處（34.8%） | 中。要動 `verdict` 與關係對 |
| **F** | Q9 位置規則補正位判定 | 252 處（12.6%） | 中。塞爾特十字有 10 個位置要各寫一套 |

※ 同一組牌可能同時踩到多條，所以百分比會超過 100%。

**A 期一期就能解掉超過一半的可見瑕疵**，而且是純文字層、零風險。建議先做完 A、B 再評估其他。

## 四、測試

| 項目 | 斷言 |
|---|---|
| Q1 | `verdict` 要有唯一的 `primaryIndex`；三個區塊的敘述不得各自宣告「最重要」 |
| Q2 | 宮廷牌文字裡不得同時出現「份量最重／最輕」與「只是輔助／也有一定份量」 |
| Q3 | 牌對標籤不得使用「增強」「削弱」這類價值判斷詞 |
| Q4 | 十張牌陣不得判為「生活小事」；三張牌陣不得判為「人生級的轉折」 |
| Q6 | 階段終點數字 ≤ 3 時，結語不得出現「收尾」 |
| Q8 | 結語的提問不得重複前文已陳述的事實 |
| Q9 | 四個牌陣在全正位時都要有至少一條位置判定 |

### 過程中的兩次自我修正

**一、檢查條件量錯了東西。** 第一次重跑時 Q7／Q8／Q9 歸零，但 Q1～Q4、Q10 數字一動也沒動。
原因不是沒修好，是檢查量的是「結構前提」而非「使用者看得到的缺陷」：

| 編號 | 原本在量 | 應該量 |
|---|---|---|
| Q2 | 整段文字有沒有那兩個詞 | **同一句裡**有沒有（修法就是拆成兩句，詞當然還在） |
| Q3 | `relation` 是不是 enhance | **標籤有沒有用價值判斷的詞**（relation 由元素決定是對的） |
| Q4 | 有沒有誤判 | 判了**有沒有加註**（決議是加註，判定本來就不改） |
| Q1 | 三個指標指不指同一張 | 指不同張是正常的，**文字有沒有說清楚哪張是主牌** |
| Q10 | 有沒有跨距關係 | 有跨距**而沒說明距離** |

**二、修 Q9 時自己踩了 v9 的坑。** 補「正位側判定」時直接假設正位＝好，寫出
「環境的錢幣五正位：外在條件站在你這邊」—— 錢幣五是匱乏、被排除在外（polarity −0.7）。
**普查檢查只量「區塊有沒有消失」，完全沒抓到這個錯，是人工讀樣本才發現的。**

修正後改成極性與正逆位兩個軸分開看：

| | 正位 | 逆位 |
|---|---|---|
| 牌義正向 | 助力使得出來 | 助力有但沒出來 |
| 牌義負向 | 阻力全開 | 阻力在減弱 |

人工複檢的結果：

```
正面影響的寶劍十正位：這一格該是助力，牌本身卻偏負面，實際上幫不上什麼。
正面影響的寶劍六逆位：這份助力是有的，只是現在沒有往外使出來。
希望與恐懼的聖杯四正位：這一格偏向恐懼那一邊，你擔心的成分多過期待的。
環境的錢幣五正位：外在條件並不友善，這一塊得自己扛。
```

### 給下一輪的提醒

**檢查歸零不等於文字正確。** 自動檢查只量得到「我想得到的缺陷」，
新寫的文字如果犯了沒被列進檢查的錯，數字一樣漂亮。
每次改完都要人工讀幾組，而且要挑最容易寫反的組合（負面牌在助力位、正向牌在阻力位）。
