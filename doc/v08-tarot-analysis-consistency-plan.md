# 判斷依據的一致性與牌理精度：第八版計畫書

- 建立日期：2026-10-14
- 適用專案：Tarot-backend、Tarot-frontend
- 前置：規則 1～11、牌對辭典（v5／跨花色已補完）、v7 敘述品質
- 狀態：草案，待確認
- 來源：三份外部批判，對象都是「過去 權杖國王正位／現在 女祭司逆位／未來 錢幣二正位（工作）」這組牌

## 這版在處理什麼

v7 修掉的是**句子內部**的矛盾。這版處理的是**區塊之間**的矛盾：每個區塊各自算、各自下結論，合起來看才發現在互相打架。

三份批判指向同一個結構性問題：**各區塊是獨立的輸出端，沒有共同的事實基礎，也沒有任何一致性檢查**。表徵有三類：

1. 同一個詞指不同的量（「情感」「影響力」各有兩三套意思）
2. 同一件事有多個互斥結論（主題判定有三個出處、大牌份量有兩種說法）
3. 數值層的假精確（63% 來自三個極小數的比值；雷達圖座標軸與實際值域差四倍）

## 二、確認成立的缺陷

### 甲、同一個詞指不同的量

#### A1 「情感」同時指兩件事

| 出處 | 指什麼 | 資料來源 |
|---|---|---|
| 「主要在講**情感**」 | 四軸的 emotion | `quant.energy`，**含大牌**。本局 0.25 全來自女祭司（水） |
| 「缺少聖杯（**情感**）」 | 聖杯花色 | `theme.missingSuits`，**只看小牌** |

兩句都沒算錯，放在同一份報告裡就是矛盾。同源問題還有「水的面向最突出」——那是元素，不是花色。

批判說「牌面缺乏聖杯卻斷言主要在講情感，是演算法抓錯重點」。**算法沒錯，是命名錯**：女祭司的水元素本來就該貢獻情感軸。

#### A2 「影響力」有三套算法

| 文字 | 實際算的 | 本局 |
|---|---|---|
| 「約 63% 的影響力集中在它身上」 | `contributions.share`（DI 貢獻佔比） | 權杖國王 63% |
| 「大牌…影響力過半」 | `weights.majorWeightShare`（牌卡權重佔比） | 女祭司 50% |
| 「它影響力夠大，推進時會卡」 | `quant.resistance`（逆位權重比） | 女祭司 |

有一份批判因此把兩張牌搞混，寫成「女祭司被渲染成影響力過半」。**讀者的誤讀就是這個缺陷的證據。**

#### A3 名詞在報告裡交替使用

情感／聖杯、行動／權杖、物質／錢幣，同一份報告裡兩套講法混用。

### 乙、同一件事有多個互斥結論

#### A4 主題判定有三個出處，給出三種答案

| 區塊 | 說法 | 來源 |
|---|---|---|
| 整體看起來 | 主要在講「情感」 | `quant.energy` 最大軸 |
| 問題對照 | 牌面以權杖（行動）、錢幣（物質）為主 | `question.alignment`，只看小牌花色 |
| 元素與數字 | 缺少聖杯（情感），沒有著墨 | `theme.missingSuits` |

三個區塊各自獨立判斷，沒有任何一致性檢查。

**這組矛盾本身是好材料**：重心落在情感面向、但檯面上的牌組是權杖與錢幣 —— 可以讀成「表面在處理事情，真正卡住的是沒說出口的那塊」。目前卻是三段互打。

#### A5 大牌份量前後打架（v7 已修一半，仍不夠）

「大牌只有 1 張，議題偏向日常，由個人可控」隔兩段變成「大牌張數雖然不多，份量卻重，影響力過半，有些部分不是你能完全掌控的」。

v7 已讓後者改口為「張數雖然不多」，但**兩句的結論仍相反**（可控 vs 不完全可控）。

#### A6 「偏向日常」的判定基準有問題

三張牌裡一張大牌是 33%，**高於 78 張牌裡大牌的自然比例 28%**（22/78）。拿「是否過半」當門檻，在小牌陣裡幾乎永遠判成「日常」。

#### A7 事情規模三句三個方向

「需要認真看待」→「分量越走越輕，慢慢回到日常」→「影響力過半、不完全可控」。

#### A8 焦點牌被講兩次

`theme.text` 與 `weights.text` 都以「焦點牌是現在的女祭司逆位」開頭。

#### A9 同一件事在報告裡講四次

女祭司逆位使不上力，出現在：推進卡、牌對削弱、互相矛盾、結語。

### 丙、數值層的假精確

#### A10 63% 是三個極小數的比值

`share = 權重 × v / Σ|權重 × v|`，而三張牌的 v 分別是 **0.20 / 0.03 / 0.04**。

分子分母都極小，比值卻用兩位有效數字呈現，看起來像有實證基礎。這組權重表是自訂的，沒有外部依據。

#### A11 「推動／拉扯」標籤與正文直接衝突

`QuantPanel.vue:194` 的標籤規則是 `item.share >= 0 ? '推動' : '拉扯'`。

本局三張牌的 share 全為正（0.63 / 0.21 / 0.15），所以**逆位的女祭司也被標成「推動」**，而正文從頭到尾說它「卡」「削弱」「使不出來」。

根因：女祭司逆位的 v = **+0.03**，是個在雜訊等級的正數，卻被拿來決定一個二分類標籤。

#### A12 雷達圖座標軸與實際值域差四倍

`QuantPanel.vue:65` 把雷達圖的 `r` 軸設成 `min: 0, max: 1`，但 `energy` 的實際值是 0.00～0.25。四個點永遠擠在圓心附近，看起來像「什麼面向都很弱」。

而且雷達圖用 `energy`、底下的長條用 `contributions.share`，**兩者算法不同**，圖與文沒有共用同一套數值。

#### A13 主軸沒有差距門檻

情感 0.25 與物質 0.24 只差 **0.01**，卻直接宣告「主要在講情感」。`analysisFormatter.js:417` 只檢查 `topAxis[1] > 0`。對照之下元素判定早有 `weightedElementMargin = 1` 這道門檻，四軸漏了。

#### A14 DI 滑桿在小牌陣幾乎沒有資訊量

三張牌的樣本幾乎必然落在中間（本局 direction = neutral），卻放在最醒目的位置。

### 丁、牌理

#### A15 數字階段丟掉了已經寫好的數字主題

`NUMBER_THEMES[2] = '抉擇、平衡'` 早就存在，但 `NUMBER_STAGES` 把 1～3 一律歸成「起步期」，語意被蓋掉。錢幣二（抉擇、平衡）因此被說成「一路停在起步期」。

#### A16 大牌與小牌的數字被放進同一條尺度

大牌的編號是**愚者旅程的位置**，小牌的數字是**元素發展的階段**，兩者不是同一條序列。本局把女祭司的 II 與錢幣二的 2 當成同一回事。

#### A17 靜默剔除了最重的那張牌

「過去的權杖國王沒有數字，不計入」——把 share 63%、唯一明確「推得動」的牌從階段判斷裡拿掉，剩兩張算出「原地踏步」。**這個結論是剔除規則的產物，不是牌面的訊息。**

#### A18／A19 正逆位被當成好壞（移到 v9）

「由逆轉正，有解套的走勢」、錢幣二正位被讀成「好轉」—— 這兩條的根因是**整套系統預設「正位＝加分、逆位＝扣分」**。

波及面比這版其他所有項目加起來都大（量化、權重、位置規則、辭典短語全都要重看），所以**獨立成 `doc/v09-tarot-polarity-plan.md`**，不在 v8 處理。

## 三、值得採納的設計意見

| # | 意見 | 說明 |
|---|---|---|
| B1 | 宮廷牌應保留「人物／性格」兩種讀法 | 現在「問題沒提到其他人，把它當成你自己的姿態」是**把預設規則當判斷**。宮廷牌落在過去位很常指具體的人（前主管、前團隊的做事風格），直接關掉這個可能性等於放棄這組牌最有資訊量的入口 |
| B2 | 結語應給提問而非宣判 | 「照目前走向，未來會停在錢幣二正位」是宣判式。塔羅的價值在把選項與該問的問題攤開，例如「那份使不出來的助力，是你還沒決定，還是在等別人表態？」 |
| B3 | 量化改成分級而非百分比 | 63% 改成主導／次要／輔助三級，或把權重規則攤開給使用者看 |
| B5 | 關係徽章（增強／削弱）降級 | 要先澄清一半是誤解：牌對文字來自辭典，是具體句子，不是靠標籤生成。但 `kindLabel`（順承／橫跨）資訊量更高，`relationLabel` 並列時最低 |

## 四、批判中不成立的部分

記下來，避免被當成待辦。

| 批判 | 實情 |
|---|---|
| 「女祭司被渲染成影響力過半、導致全面卡住」 | 63% 是權杖國王，女祭司的 DI 貢獻只有 21%。會誤讀是因為 A2 |
| 「雷達圖把情感軸拉高，與牌義脫節」 | 情感 0.25 確實來自女祭司的水元素。問題在命名（A1）與座標軸（A12），不在計算 |
| 「情感軸在缺少聖杯時應歸零」 | 不可行。大牌本來就有元素屬性，歸零會讓只抽到大牌的牌陣四軸全空 |
| 「牌面關係是生硬的二分法，無法反映因果」 | 實際輸出是辭典句子（「有人掌舵，但心裡還有疑慮。」），標籤只是附帶徽章 |
| 「行動軸幾乎貼著圓心」 | 行動 0.21 與最高的情感 0.25 其實相近。是**四個軸都貼著圓心**（A12），不是行動特別低 |

## 五、改法

### 5.1 單一事實來源與矛盾檢查（最優先）

目前每個 `buildXxxText` 各自從 `result` 取數、各自下判斷。改成：

1. 在 `formatAnalysis` 開頭算出一組 **`verdict`**（共同結論）：主導面向、主導牌組、缺少牌組、議題層級、最重的牌與其位置、整體方向。
2. 各區塊的文字**一律引用 `verdict`**，不得自己重算。
3. 收尾加一道 `assertConsistency(verdict, texts)`，在測試環境中對互斥組合直接拋錯（例如同時出現「偏向日常」與「不完全可控」）。

這條解掉 A4、A5、A7。

### 5.2 詞彙分流（解 A1、A2、A3）

| 概念 | 統一用詞 | 來源 |
|---|---|---|
| 四軸（含大牌元素） | **面向**：行動／情感／思維／物質 | `quant.energy` |
| 小牌花色 | **牌組**：權杖／聖杯／寶劍／錢幣 | `theme.dominantSuits` |
| DI 貢獻佔比 | **帶動幅度** | `contributions.share` |
| 牌卡權重佔比 | **份量** | `weights.majorWeightShare` |
| 逆位權重比 | **阻力** | `quant.resistance` |

改寫範例：

- 「這組牌主要在講『情感』」→「重心落在**情感面向**（來自女祭司的水元素）」
- 「缺少聖杯（情感）」→「**沒有抽到聖杯牌組**，情緒與人際這塊沒有直接著墨」
- 「約 63% 的影響力」→「它**帶動了整體走向的大部分**」（配合 5.5 改成分級）

兩句放一起就不再打架，反而成立：重心在情感面向、檯面上卻沒有聖杯牌組。

### 5.3 主軸加差距門檻（解 A13）

`ruleConfig` 新增 `QUANT.axisMargin = 0.05`：

| 條件 | 文字 |
|---|---|
| 第一名 − 第二名 ≥ 0.05 | 「重心落在○○面向。」 |
| 差距 < 0.05 | 「○○與○○份量相當，沒有單一主軸。」 |
| 全為 0 | 不輸出 |

本局 0.01 → 走第二種。

### 5.4 大牌份量改用相對基準（解 A6）

把「是否過半」換成「是否高於牌組自然比例」：大牌 22/78 ≈ 28%、宮廷 16/78 ≈ 21%。

| 大牌佔比 | 判定 |
|---|---|
| ≥ 40% | 外在／命運主導 |
| 28%～40% | 比例偏高，有一定的外在成分 |
| < 28% | 偏向日常，個人可控 |

本局 33% → 中間級，與「份量過半」不再衝突。v7 加的 `MAJOR_COUNT_FATE_THRESHOLD = 3` 保留為大牌陣的補充條件。

### 5.5 量化改分級（解 A10、A11、A14）

- **不再輸出百分比**。`share` 依絕對值分三級：主導（≥0.4）／次要（0.15～0.4）／輔助（<0.15）。
- **「推動／拉扯」加死區**：`|share| < 0.1` 一律標成「影響有限」，不分正負。本局女祭司 +0.21 仍為正，但要配合下一條。
- **正逆位納入標籤**：逆位的牌即使 share 為正，標籤也要寫成「推動（逆位，力道打折）」之類 —— 或更乾脆，**標籤改為三段式：份量等級＋正逆位，不再用推動／拉扯的二分**。
- **DI 滑桿**：牌數 < 4 時隱藏或加註「牌數少，這個指標僅供參考」。

### 5.6 雷達圖座標軸貼合實際值域（解 A12）

`max: 1` 改為動態：`Math.max(0.3, 最大值 × 1.3)`，並在圖上標註刻度。同時在圖旁註明「這張圖用的是四軸能量，與下方的帶動幅度算法不同」。

### 5.7 數字階段帶上數字主題（解 A15）

```
現行：現在 起步期（2） → 未來 起步期（2）。一路停在起步期，沒有往前也沒有退。
改為：未來 錢幣二（2．抉擇、平衡）。只有一張有數字的小牌，看不出階段走向。
```

並修正「一路停在○○」：同階段不等於停滯，數字相同代表**同一個主題被重複強調**（`NEUTRAL_CLUES` 的 `numberRepeat` 本來就是這個措辭）。

### 5.8 大牌與小牌的數字分流（解 A16、A17）

- `analyzeNumberStage` 只收 `kind === 'pip'`。
- 大牌的編號改列為「旅程位置」，在「整體在說什麼」交代，不進階段序列。
- **被排除的牌要講清楚為什麼，而且不能只用一句帶過**：
  ```
  權杖國王是宮廷牌、女祭司是大牌，都不走小牌的數字階段。
  但權杖國王是這組牌帶動幅度最大的一張，看階段時要記得它不在這條線上。
  ```
  解掉 A17 的「靜默剔除」。

### 5.10 宮廷牌保留兩種讀法（B1）

```
現行：問題沒提到其他人，把它當成你自己的姿態與做事方式。
改為：可以當成你自己的做事方式，也可以是某個具體的人（落在過去位時，常是前主管或前一個團隊的風格）。
      問題裡沒提到其他人，所以先按前者看，但兩種都值得對照。
```

### 5.11 結語改成提問（B2）

保留現有的事實陳述，但把最後的宣判句換成一到兩個提問：

```
現行：照目前走向，未來會停在錢幣二正位。
改為：接下來值得自己回答兩件事：那份使不出來的助力，是你還沒決定，還是在等別人表態？
      未來那張錢幣二是「調度得過來」還是「一直在調度卻沒落地」？
```

### 5.12 去重（解 A8、A9）

- `buildWeightText` 拿掉焦點牌開頭，由 `buildThemeText` 獨佔。
- 同一張牌的同一個狀態，整份報告最多講兩次（一次在它自己的區塊、一次在結語）。實作上由 5.1 的 `verdict` 記錄已提及的 `(index, 面向)`。
