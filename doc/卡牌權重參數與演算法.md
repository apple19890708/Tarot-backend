## 一、總覽

這套演算法把一次抽牌換算成幾個有界的數值，用來回答「這組牌對你問的問題，指向哪個方向、力道多強」。

計算流程：

```
每張牌 → 維度向量 + 極性 + 權重
            ↓  乘上問題領域的關注度、牌陣位置權重、正逆位修正
        每張牌的投影值 v ∈ [-1, 1]
            ↓  以 (位置權重 × 大小牌權重) 作加權平均
        指向分數 DI ∈ [-100, 100] → 分級顯示
```

四個輸出指標：

| 指標 | 值域 | 意義 |
|---|---|---|
| 指向分數 DI | −100 ~ 100 | 這組牌對該問題的整體傾向，畫面上只顯示分級 |
| 四軸能量 energy | 0 ~ 1（每軸） | 力氣花在哪個面向，不代表好壞 |
| 動能 momentum | 0 ~ 1 | 正位牌在該領域的推力 |
| 阻力 resistance | 0 ~ 1 | 逆位牌佔的份量 |
| 明朗度 confidence | 0 ~ 1 | 訊號是否集中，低於 0.5 時畫面顯示提醒 |

## 二、每張牌的三個參數

### 2.1 維度向量 dimensions

四個維度與四元素一一對應，這不是巧合，而是塔羅花色體系本身的設計：

| 維度 | 元素 | 花色 | 意義 |
|---|---|---|---|
| action 行動 | 火 | 權杖 | 行動、衝勁、推進 |
| emotion 情感 | 水 | 聖杯 | 情感、人際、感受 |
| logic 思維 | 風 | 寶劍 | 思維、判斷、溝通 |
| material 物質 | 土 | 錢幣 | 物質、金錢、實務 |

因為這層對應關係，**小牌的維度向量可以直接由花色推導**，不需人工標註。大牌則使用金色黎明體系已指定的元素。少數跨面向的牌（例如錢幣十兼具物質與情感）另行覆寫。

計算時維度會先正規化成總和 1，這是公式值域成立的前提。

### 2.2 極性 polarity

值域 −1 ~ 1，代表牌義的正負向。這是**唯一無法完全推導**的資訊，取得方式分三種：

| 牌種 | 取得方式 |
|---|---|
| 大牌（22 張） | 人工給定的極性表 |
| 數字牌 | `數字極性 + 花色偏移`，推導後再視需要覆寫 |
| 宮廷牌 | 固定 +0.2（多為人物描述，偏中性） |

**數字極性**（沿用既有的數字主題語意）：

| 數字 | 主題 | 極性 | | 數字 | 主題 | 極性 |
|---|---|---|---|---|---|---|
| 1 | 開始 | +0.5 | | 6 | 和諧、回復 | +0.5 |
| 2 | 抉擇、平衡 | 0.0 | | 7 | 考驗、反思 | −0.3 |
| 3 | 成長、合作 | +0.5 | | 8 | 推進、掌控 | +0.4 |
| 4 | 穩定 | +0.3 | | 9 | 臨界、獨立 | −0.1 |
| 5 | 衝突 | −0.6 | | 10 | 完成或過載 | +0.2 |

**花色偏移**（RWS 傳統上寶劍偏艱難）：權杖 +0.05、聖杯 +0.05、錢幣 +0.05、寶劍 −0.25

**為什麼需要覆寫**：數字啟發式在 7、9、10 最不準，因為同一個數字的四個花色差異極大。例如數字 9 推導出 −0.1，但聖杯九是願望成真、錢幣九是豐收富足，兩張都應該是強正向；寶劍九才是焦慮。目前 78 張中有 15 張採用覆寫值，清單會隨實際使用逐步補齊。

### 2.3 基礎權重與強度

| 牌種 | 基礎權重 | 說明 |
|---|---|---|
| 大牌 | 3 | 影響力最大 |
| 宮廷牌 | 2 | 次之 |
| 數字牌 | 1 | 基準 |

基礎權重**放進加權平均的分母**，而不是乘進分數，這樣值域才不會爆開。

宮廷牌另有階級強度修正（只影響力道，不影響正負）：侍者 0.6、騎士 0.9、王后 0.8、國王 1.0

## 四、問題領域權重

每個領域對四個維度的關注度，**一律非負且總和為 1**（這是公式值域成立的前提）。使用者可在畫面上直接指定問題類型；未指定時由關鍵詞比對，再比對不到則使用綜合。

|---|---|---|---|---|
| 工作 work | 0.35 | 0.10 | 0.25 | 0.30 |
| 財務 money | 0.15 | 0.05 | 0.25 | 0.55 |
| 感情 love | 0.15 | 0.60 | 0.15 | 0.10 |
| 人際 social | 0.15 | 0.55 | 0.20 | 0.10 |
| 學業與決策 study | 0.15 | 0.10 | 0.60 | 0.15 |
| 綜合 general | 0.25 | 0.25 | 0.25 | 0.25 |

**領域判定的優先序**：使用者指定 → 關鍵詞比對 → 綜合（均等權重）

關鍵詞清單在 `ruleConfig.js` 的 `QUESTION_DOMAINS`。

## 五、牌陣位置權重

同一個牌陣內的位置權重總和為 1。手動選牌沒有牌陣位置，所有牌平均分配。

| 牌陣 | 位置與權重 |
|---|---|
| 時間之流 | 過去 0.20、現在 0.35、未來 0.45 |
| 直指核心 | 問題核心 0.30、障礙 0.20、對策 0.30、資源 0.20 |
| 指引之星 | 問題 0.10、過去影響 0.10、負面影響 0.15、現在 0.20、正面影響 0.15、未來 0.15、終局 0.15 |
| 自選牌（手動） | 每張平均 1/n |

**關於「未來」的權重**：原本設定 0.50，但那代表單一張牌佔掉一半分數，抽到一張極端牌就會主導整個結果。下修為 0.45 後，未來仍是最重的位置，但過去＋現在（0.55）略高於未來，單張牌不會獨斷。

### 為什麼逆位不乘負數

專案規則明訂：**逆位代表受阻、內化、延遲或過度，不是單純相反**。乘上負數在數學上就等於「牌義相反」，會違反這條規則。因此逆位只衰減強度（×0.45），正負號維持不變，逆位帶來的阻礙另外計入「阻力」指標。

程式有測試守住這點：同一張牌的正位與逆位，DI 必須同號且逆位的絕對值較小。

## 七、演算法公式

### 7.1 單張牌的投影值

```
d[k]        = dimensions[k] / Σ dimensions          # 正規化成總和 1
relevance   = Σ( d[k] × domain[k] ) / max(domain)   # 相對吻合度，∈ [0,1]
v           = polarity × relevance × 逆位修正 × 階級強度
```

`v` 的值域 **−1 ~ 1 由建構保證**：

- 正規化後 `Σd[k] = 1`，且 `domain[k] ≥ 0`
- 故 `Σ(d×domain) ≤ max(domain)`，相除後 `relevance ∈ [0,1]`
- `polarity ∈ [-1,1]`，其餘修正值皆 ≤ 1
- 因此 **不需要任何夾擠（clamp）**

**為什麼 relevance 要除以 `max(domain)`**：若直接用 `Σ(d × domain)`，單一元素的牌在均等領域只會拿到 0.25，等於所有牌一律打四折，DI 值域會被壓縮到 ±25，「強烈」門檻永遠達不到。改成相對值後，「完全對題」的牌 relevance = 1，值域才展得開。

### 7.2 指向分數

```
w   = 位置權重 × 基礎權重（大牌 3／宮廷 2／數字 1）
DI  = 100 × Σ(w × v) / Σ(w)
```

因為 `v ∈ [-1,1]` 且 `w > 0`，加權平均必落在 `[-1,1]`，所以 `DI ∈ [-100, 100]`。**沒有魔術常數，沒有夾擠。**

### 7.3 四軸能量

```
energy[k] = Σ( w × d[k] × 逆位修正 ) / Σ(w)
```

此處**不乘極性**：雷達圖表達的是「力氣花在哪個面向」，不是好壞。

### 7.4 動能與阻力

```
momentum   = Σ( w × relevance × 是否正位 ) / Σ(w)
resistance = Σ( w × 是否逆位 ) / Σ(w)
```

注意：這裡的阻力有乘上牌陣位置權重，與另一條規則的「逆位權重比」**不是同一個數字**（實測 0.15 vs 0.25）。因此畫面上阻力**只顯示這一個**，避免兩個算法不同的數字同時出現造成矛盾。

### 7.5 明朗度

```
confidence = 1
           − 0.30 × 元素或極性未知的牌權重佔比
           − 0.25 × 四軸能量的分散程度（正規化熵）
           − 0.15 × min(1, 矛盾點數 / 牌數)
           − 0.10 × （領域未判定 ? 1 : 0）
```

結果限制在 0 ~ 1。

### 7.6 指向分級

| DI 區間 | 指向 |
|---|---|
| ≥ +60 | 明顯順利 |
| +20 ~ +60 | 偏順利 |
| −20 ~ +20 | 好壞參半 |
| −60 ~ −20 | 偏不順 |
| ≤ −60 | 明顯不順 |

畫面上**只顯示分級文字與儀表指針位置，不顯示 DI 數字**，避免造成假精確感。

### 7.7 貢獻佔比

每張牌對 DI 的貢獻，用來在畫面上標出誰推高、誰拉低：

```
share = (w × v) / Σ|w × v|
```

正值為推動，負值為拉扯。

## 八、實測鑑別度

| 牌組（時間之流、綜合領域、皆正位） | DI | 分級 |
|---|---|---|
| 太陽、世界、聖杯十 | 90.0 | 明顯順利 |
| 權杖二、聖杯二、寶劍二 | −8.5 | 好壞參半 |
| 塔、惡魔、寶劍十 | −82.1 | 明顯不順 |
| 塔、惡魔、寶劍十（全部逆位） | −37.0 | 偏逆向（衰減但未翻正） |

同一組錢幣牌（錢幣九、錢幣十、錢幣八）在不同領域：

| 領域 | DI | 分級 |
|---|---|---|
| 財務 | 53.8 | 偏順利 |
| 工作 | 48.0 | 偏順利 |
| 感情 | 18.2 | 好壞參半 |
| 學業與決策 | 14.8 | 好壞參半 |

領域越不相關，分數越靠近中性——這是正確的行為：當牌面與你問的領域無關時，這組牌本來就「沒說什麼」。

## 九、已知限制

1. **障礙類位置的語意**：「障礙」「負面影響」這類位置本來就預期抽到負面牌，目前所有位置一律以 +1 計入極性。障礙位抽到重度負面牌會拉低 DI（正確），但抽到強正向牌時語意會曖昧。實務上少見，暫不處理。
2. **極性覆寫清單仍在成長**：目前 15 張，其餘數字牌使用推導值。推導值在數字 7、9、10 最不準。
3. **大牌極性為主觀判斷**：22 張的數值依 RWS 傳統牌義給定，不同流派可能有不同看法，可隨時調整。
4. **此為規則計算的傾向，不是預測**：畫面文字已明確標示。

## 十、調整指引

| 想調整什麼 | 改哪裡 |
|---|---|
| 某張大牌的極性 | `ruleConfig.js` 的 `MAJOR_POLARITY`（英文）與 `MAJOR_POLARITY_ZH`（中文），兩處都要改 |
| 某張小牌不準 | `cardDimensions.js` 的 `CARD_OVERRIDES` 加一筆 |
| 數字或花色的推導基準 | `ruleConfig.js` 的 `NUMBER_POLARITY`、`SUIT_POLARITY_BIAS` |
| 領域關注度 | `ruleConfig.js` 的 `QUESTION_DOMAINS[*].dimensions`，**改完要確認總和仍為 1** |
| 領域關鍵詞 | `ruleConfig.js` 的 `QUESTION_DOMAINS[*].keywords` |
| 牌陣位置權重 | `spreads.js` 各位置的 `weight`，**同一牌陣總和須為 1** |
| 逆位衰減、分級門檻、明朗度係數 | `ruleConfig.js` 的 `QUANT` |

改完請執行 `npm test`。測試會驗證值域、逆位不翻轉、權重比例與領域鑑別度。
