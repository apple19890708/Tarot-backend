## 2026-11-04

### 分析文字口語化
- 「整體看起來」：改說「往順利／往不順拉最多的是…」；推力達高、阻力不到高才說「推得動」；兩者都低時說局面偏平靜
- 強弱分級改成三段門檻 `QUANT.levels`（momentum／resistance／confidence／focus），由 2 萬組隨機牌陣實測分布訂出；回傳新增 `quant.levels`，`confidenceLow` 改由信心分級算，拿掉 `confidenceLowThreshold`
- 「整體在說什麼」：焦點寫成「落在『X』位置的…」，花色配對講兩者怎麼互動，宮廷牌階級對應主題；可控性用「多半在你自己處理得來的範圍」
- 「各個位置看出什麼」改口語；負面牌落在正向位置（資源、助力）、好牌落在負面影響位置時換讀法，不再說「這格沒用」
- 「元素」只講元素：缺的花色分成「被大牌元素補上」與「真的沒有」，避免「火元素最多」又說「沒有權杖」；結語用同一套判斷
- 宮廷牌：角色說明在總結講一次，各張只講樣貌、逆位與影響，修掉「用得不順／往順利」「比較重要／影響不大」這類互相矛盾的句子；「王后」改「皇后」
- 結語重排：整體 → 關鍵牌 → 焦點與沒出現的面向 → 要留意 → 走向 → 最後一張 → 自問的問題；用詞「拉動」改「影響」，「份量差不多」保留（使用者決定）

### API
- `POST /api/market/snapshot`：行情快照（不呼叫 AI）；narrate 的串流在股市諮詢時先送 `market` 事件
