## 目標

只使用現有資料（牌陣位置、正逆位、元素、數字、權重、問題文字），不需另外撰寫牌組內容。每條規則都輸出結構化結果與 `evidence`（依據哪幾張牌，記為牌的索引），文字由 `analysisFormatter.js` 組成，結果同時提供給 AI 解讀。

規則程式拆成多個檔案，關鍵詞與門檻放在 `src/data/` 的設定檔：

```
src/services/rules/
  questionRules.js   規則 7
  positionRules.js   規則 8
  numberStageRules.js 規則 9
  weightRules.js     規則 10
```

規則 4 的補充直接修改 `combinationRules.js`。

### 規則 7：問題領域對照

1. 依問題文字的關鍵詞判斷領域，可同時屬於多個領域；沒有命中任何關鍵詞（或問題空白）時不判定。

| 領域 | 關鍵詞（初版） | 對應花色 |
|---|---|---|
| 工作 | 工作、職場、轉職、離職、面試、主管、老闆、同事、升遷、專案、公司、事業、創業 | 權杖、錢幣 |
| 財務 | 錢、薪、收入、投資、財務、存款、負債、買房、股票 | 錢幣 |
| 感情 | 感情、愛、伴侶、交往、曖昧、復合、分手、結婚、男友、女友、喜歡、對象 | 聖杯 |
| 人際 | 朋友、家人、人際、相處 | 聖杯 |
| 學業與決策 | 考試、學業、讀書、選擇、決定、該不該 | 寶劍 |

2. 只用小牌（數字牌與宮廷牌）的花色比對，大牌不計。
3. 判定：

| 結果 | 條件 | 文字方向 |
|---|---|---|
| `aligned` 對焦 | 對應花色是小牌中張數最多的花色（同數並列也算） | 牌面直接回應你問的領域；與其他花色並列最多時，改說「有回應，但沒有特別集中」 |
| `partial` 部分 | 對應花色有出現，但不是最多 | 有回應，但重心在另一個領域 |
| `mismatch` 偏離 | 對應花色完全沒出現 | 你問的是 A，牌面講的是 B，真正卡住的可能在 B |
| `noMinor` 無法比對 | 全部是大牌 | 議題超出單一生活領域 |

### 規則 8：牌陣位置

依牌陣的位置 `key` 套用，沒有定義的牌陣略過。

**時間之流（past → present → future）**

- 正逆位走勢（看三張的正逆位組合）：

| 型態 | 判定 |
|---|---|
| 三張皆正位 | 順勢 |
| 三張皆逆位 | 整體卡住 |
| 現在逆位、未來正位 | 解套 |
| 現在正位、未來逆位 | 受阻將至 |
| 其他 | 起伏 |

- 起點與結果：比較「過去」與「未來」的元素關係。同元素或友好為「延續」、對立為「翻轉」、中性為「轉換」。

**直指核心（core、challenge、advice、resource）**

- 障礙與對策的元素關係：對立為「對策能克制障礙」；同元素為「對策與障礙同質，用同樣的方式應對可能加重問題」；友好為「對策可能助長障礙」；中性不判定。
- 資源逆位：「優勢存在，但目前沒有發揮」。
- 問題核心是大牌：「核心議題超出個人能完全掌控的範圍」。

**指引之星（question、past、negative、present、positive、future、outcome）**

- 過去影響 → 現在 → 未來：套用時間之流的正逆位走勢。
- 正面影響逆位：「助力存在，但目前沒有發揮」；負面影響逆位：「負面影響正在減弱，或轉為內在」。
- 負面影響與正面影響的元素關係：對立為「助力正好能抵銷阻力」；同元素為「助力與阻力來自同一個面向」。
- 問題與終局：套用時間之流的起點與結果判定（延續、翻轉、轉換）。

### 規則 9：數字階段

使用 1.4.1 節化簡後的數字（宮廷牌不計）：

| 數字 | 階段 |
|---|---|
| 0 | 起點之前 |
| 1～3 | 起步期 |
| 4～6 | 發展與穩定期 |
| 7～9 | 考驗與臨界期 |
| 10 | 結束或過載 |

- 主要階段：某階段的張數 ≥ 有數字牌數的一半，且是唯一最多的階段時成立；否則記為「階段分散」（例：2 張分屬不同階段時不成立）。
- 走向：依牌的順序，比較第一張與最後一張有數字的牌所屬階段，判定「往前推進」、「回到前段」或「停在同一階段」。
- 有數字的牌少於 2 張時，不判定走向。

### 規則 10：權重分析（擴充規則 3）

權重維持：大牌 3、宮廷牌 2、數字牌 1。

| 項目 | 計算 | 判定門檻 |
|---|---|---|
| 議題份量 | 平均權重＝總權重 ÷ 張數 | ≥ 2.2「重大」；1.6～2.2「中等」；< 1.6「日常」 |
| 份量重心 | 權重最高的位置；同分取順序較前者（即現有焦點牌） | 文字說明重心落在哪個位置 |
| 份量走向 | 牌陣有時間順序時（時間之流、指引之星），比較第一張與最後一張的權重 | 後者較重為「越來越重大」、較輕為「逐漸回到日常」、相同為「份量持平」 |
| 加權元素 | 每張牌的權重加到它的元素上 | 最高者至少比第二名多 1 分才成立；與依張數計算的主導元素不同時，另外說明「大牌加重了 X 元素的份量」 |
| 阻力份量 | 逆位牌權重 ÷ 總權重 | ≥ 0.5「阻力偏高」；0.3～0.5「有阻力」；< 0.3「阻力低」 |
| 大牌份量比 | 大牌權重 ÷ 總權重 | 只作補充說明；規則 3 的「外在主導」仍依張數判定（見待確認事項） |

例：1 張大牌＋2 張數字牌，平均權重 5 ÷ 3 ≈ 1.67，為「中等」；大牌份量比 3 ÷ 5 = 60%。

### 規則 4 補充：讓「中性」也有內容

元素關係為中性時，改用以下線索組成說明（依序取有成立的項目）：

1. 正逆位變化：正 → 逆為「受阻」，逆 → 正為「解套」
2. 大小牌轉換：大 → 小為「大方向落到日常執行」，小 → 大為「日常累積引發較大的變化」
3. 數字方向（化簡後）：上升為「推進」，下降為「回頭」，相同為「重複強調」

三項都不成立時，才使用原本的「沒有明顯的互相影響」。這三項也一律加到配對的 `tags`。

### 前端

- 「判斷依據」新增四個區塊：問題對照、位置解讀、數字階段、份量分析
- 份量分析以「傾向」顯示（例如「議題份量：中等」「阻力：偏高」），不顯示精確分數
- 點選某條判斷時，標示 `evidence` 對應的牌（第二批再做也可以）

### 測試

每條規則至少涵蓋門檻邊界：平均權重剛好 2.2 與 1.6、阻力份量剛好 0.5 與 0.3、加權元素差 1 分與差 0 分、問題命中多個領域、全部大牌、有數字的牌少於 2 張。
