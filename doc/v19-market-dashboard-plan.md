# v19　大盤概況改成「股市總覽」：使用者自訂區塊與卡片

建立日期：2026-11-08
狀態：進行中（階段 1～3 完成，待階段 4 手機與日夜檢查）

## 一、目標

股市追蹤的第一個分頁「大盤概況」目前是固定版面：重點卡 → 美國經濟數據 → 漲跌家數 → 類股熱力圖 → 三大法人 → 美股三組。每個人關心的不一樣（只做台股的不需要美股三組、存股的人想先看自己的持股），改成**使用者自己決定要看哪些區塊、什麼順序、區塊裡放什麼**的個人首頁。

**不做的事**

- 不做自由拖拉、改大小的格狀版面（像 Grafana）：手機上難操作、版面容易亂，維護成本高。區塊一律滿版、由上往下排。
- 不讓使用者自己寫公式或接外部資料來源；區塊只能從我們提供的清單挑。
- 不做每台裝置不同的版面、不做分享版面給別人。
- 不改後端大盤概況的抓取方式：概況是所有人共用一份快取，不會因為某人隱藏了美股就不抓（第三節說明）。
- 不動塔羅首頁；這裡的「首頁」指股市追蹤的第一個分頁。

## 二、規格

### 2.1 區塊清單

第一批（現有內容拆出來，預設全部顯示、順序同現在）：

區塊本身可以顯示／隱藏、排序；**區塊裡的卡片也可以由使用者增減、排序**（使用者決定）：

| 區塊 | 卡片可以增減、排序的範圍 |
| --- | --- |
| 重點卡 | 大盤概況裡的指數、匯率、台指期夜盤，**加上自己追蹤的個股**（使用者決定可以），最多 8 張 |
| 美國經濟數據 | CPI、核心 CPI、PCE、核心 PCE、非農 |
| 漲跌家數 | 上市、上櫃 |
| 類股熱力圖 | 不挑卡片；設定顯示全部或只看漲跌最多的前 N 個 |
| 三大法人 | 無 |
| 美股與市場情緒 | 美股 10 張卡片任選、排序（不再固定分三組；分組標題只在照預設順序時顯示） |

重點卡放個股：報價沿用自訂追蹤的摘要（`getWatchSummaries`），只能從自己的追蹤清單挑，點開一樣是走勢彈窗（台股個股用 Yahoo 代號）。追蹤清單裡刪掉的股票，重點卡上自動拿掉。

第二批（用使用者自己的資料，現在散在其他分頁）。**預設放「自選清單」區塊、指定使用者的第一個自訂清單；使用者還沒有任何清單（或清單是空的）時，這一塊改顯示「當日推薦個股」**（使用者決定）：

| 區塊 | 內容 | 資料來源 |
| --- | --- | --- |
| 我的持股總覽 | 台股、美股的市值、損益、今日損益 | 自訂追蹤（已有 `totals`） |
| 自選清單 | 指定一個清單，列出裡面的股票現價與漲跌 | 自訂追蹤＋清單 |
| 價位提醒 | 已觸發、接近觸發的提醒 | 價位提醒 |
| 今日財經新聞 | 與我追蹤相關的頭條幾則、今天的 AI 分析摘要 | 財經新聞 |
| 當日推薦個股 | 規則挑出的幾檔台股（見 2.5），附上入選理由 | 選股的全市場資料 |

### 2.2 編輯方式

- 區塊上方一顆編輯鈕（和「管理清單」一樣：筆 → 勾勾）。進入編輯模式後：
  - 每個區塊顯示：拖曳把手（桌機）、上移／下移（手機）、顯示／隱藏、齒輪（區塊設定）。
  - 最下面「新增區塊」列出還沒放的區塊。
  - 「恢復預設」一鍵回到現在的版面（要確認）。
- 編輯中的變更即時套用畫面，按勾勾才存；中途離開頁面不存（提示）。

### 2.3 資料結構與 API

- 存在 `MarketProfile.dashboard`（每個帳號一份，換裝置也一樣，不放 localStorage）：
  `{ version: 1, blocks: [{ type, visible, options }] }`
- `GET /api/market/settings` 回傳時帶 `dashboard`（沒有就是 null，前端用預設版面）；`PUT /api/market/dashboard` 整份替換。
- 後端驗證：`type` 只收已知的區塊、同一種區塊最多一個（「自選清單」區塊可以多個、各指定不同清單）、`options` 只留該區塊認得的欄位、總數上限 20；不合格的整份擋下（400）。
- 前端相容：讀到不認得的 `type` 略過；之後新增區塊種類時，舊的版面裡沒有的新區塊接在最後、**照該區塊的預設顯示與否**（階段 3 起；原本是一律不顯示，但使用者決定自選清單要預設顯示），不打亂使用者排好的順序。

### 2.4 效能

- 大盤概況的資料照舊一次抓（後端共用快取），隱藏的區塊前端不畫。
- 第二批區塊用到的資料（持股、清單、提醒、新聞）**只在有放這些區塊時才請求**，各自有骨架與錯誤狀態，一塊失敗不影響其他塊。

### 2.5 當日推薦個股（選法待確認）

目前系統沒有「推薦」功能，最接近的是「選股」（使用者自己設條件）。建議的預設選法（每天收盤後後端算一次、所有人共用、快取到隔天）：

- 範圍：上市櫃股票（不含 ETF、權證），成交量 ≥ 1000 張
- 條件：外資或投信連續買超 ≥ 3 天，且最新月營收年增 > 0，且收盤站上 20 日均線
- 排序：外資連買天數多的在前，取前 5～10 檔
- 每檔附「為什麼入選」的白話理由（例：外資連買 5 天、營收比去年同月多 18%）
- 畫面明寫「依公開資料用固定規則挑出，不是投資建議」；文字照「股市文字要白話」的規範
