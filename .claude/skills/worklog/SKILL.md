# 寫後端工作週記

一週一個檔：`doc/worklog/<該週週一的日期>.md`，繁體中文。週一到週日算同一週。

## 找到這週的檔案

1. 依今天的實際日期算出這週的週一（例：2026-10-28 是週三，週一是 2026-10-26）。
2. `doc/worklog/2026-10-26.md` 已存在：最新日期**附加在檔尾**。
3. 不存在：新建這個檔，第一行寫標題，週日的日期要算出來：

   ```markdown
   # 工作週記（後端）2026-10-26 ～ 2026-11-01
   ```

## 每天的格式

```markdown
## YYYY-MM-DD

### <主題>（詳見 `doc/vXX-....md`）
- 改了什麼、為什麼這樣決定
- 影響到的 API 欄位或行為

### 其他
- 測試：`npm test` 共 N 項（新增涵蓋 ...）

### 待辦
- 還沒做完的事
```

## 要點

- 日期用今天的實際日期，不要寫相對時間（「昨天」「上週」）。
- 一行一件事，寫**決策與影響**，不要抄 diff。
- 動到規則或門檻時，標註對應的計畫書檔名。
- 若今天的日期區塊已存在，就補在該區塊底下，不要再開一個。
- 「待辦」只留還沒完成的；做完的要從舊區塊的待辦移除或在新區塊註明已完成。
- 新的一週開檔時，把上週還沒完成的「待辦」搬到新檔第一天的待辦裡。
- 不要把 `.env` 的值、API key、密碼寫進紀錄。
